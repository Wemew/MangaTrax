## 2. Missing requirements (B/C)

1. **M1 — Series search state/URL contract.** The design adds server-side search but never says the query is in the URL, how it survives a reload/back button, or how Clear restores the prior loaded page/scroll. Add it (it is also the deep-link target UX-010 needs).
2. **M2 — Mobile visibility of Series row actions.** With the table converted to cards, Backfill / Edit link / Blacklist stay icon-only unless the design says otherwise; mobile users cannot read `title`. Add a labelled action row in the mobile card (and keyboard order).
3. **M3 — Manual Pickup access-state details.** Define active state for `/downloads/manual-pickup` in the desktop Downloads dropdown trigger, the mobile Downloads tab and the More sheet; confirm the page keeps `active_page="downloads"` (`main.py:1655`) or introduce a first-class value with the matching `active_page` test updates (Part 5 open question 2).
4. **M4 — Bottom bar and keyboard/landscape edge cases.** Virtual-keyboard overlap when a search input is focused, bottom-sheet + landscape notches (`safe-area-inset-left/right`), and hiding the bar when a sheet/palette/dialog is open are not specified.
5. **M5 — Search results and no-results feedback on Series.** Show "N series match" and a server-driven empty state (keep the pinned `series-filter-empty` copy); show an inline retry when the search request fails; do not silently fall back to client filtering.
6. **M6 — Dashboard quick-action feedback matrix.** Per action: busy state, success toast text, failure toast text, and what happens when the action is already running / Calibre missing / no downloads. This is where Dashboard and Series differ from the palette (in-place vs navigation).
7. **M7 — Manual Pickup count freshness.** UX-004/UX-011 fetch counts once; after a user discards/fetches a pickup on another page, the badge/banner is stale. Add a refresh on `pageshow`/visibilitychange (cheap, no poll) and define the "count changed while page open" case.
8. **M8 — Card-table a11y contract.** Mobile stacked tables lose `<th>` associations; define visually-hidden table headers/labels and extend the icon-only-button/duplicate-attribute static tests to `partials/` (currently only top-level templates are scanned, `test_ui_polish.py:174`).
9. **M9 — Series header action priority on mobile.** Series has both search and Sync Calibre in one header row today; the design says Sync is full-width and search stays, but not the order/height nor what happens to the result count line. Specify (see UX-012 amendment).
10. **M10 — B/C acceptance evidence.** The acceptance criteria are source-string checks plus one manual "≤390 px" review; add explicit mobile checks for Series (no horizontal scroll at 360/390 px; every row action ≥44 px; card labels present) and for Overview (quick actions ≥44 px; banner not overlapping the tab bar).

## 5. Blockers (design not approvable as written)

1. **B1 — Header/button arithmetic and nav test contract are inconsistent.** UX-002 says 6 header buttons with 3 nav triggers; UX-003 makes Downloads a 4th dropdown trigger (7 buttons). §7 says "5 → 6" and omits the Downloads `<a>`→button change, the Downloads dropdown children/highlight expression, and the active-page literals. Evidence: `UI_ENHANCEMENT_SPEC.md:34-45,275-282`; `tests/test_nav_structure.py:74-88,94-127,190,315-328`. Fix: state 7 buttons, "only Overview is an `<a>`", and enumerate the exact test updates.
2. **B2 — UX-010 palette is not implementable as written.** The `mt:run` sessionStorage hand-off is unnecessary (all four quick actions are already global null-safe functions: `base.html:516,541,594,756`) and palette search has no page/URL contract (`main.py:1182` accepts no `search`; `series.html:23,194-233` is client-side; `releases.html:191` starts empty). Fix: closed direct-dispatch map + `?search=` bootstrap on Series/Releases + result activation + request-cancellation; update §7/new-suite acceptance.
3. **B3 — §3.2 Series server-side search lacks race/state/test-preservation mechanics.** It does not define fetch cancellation, search-mode gating of the 60 ms chain/observer/Load More, URL state, or preservation of pinned strings (`tests/test_performance_and_lazy_loading.py:124-125`; `tests/test_ui_polish.py:148-152`). Fix: add the mechanics and a §7 row.
4. **B4 — §3.2 stacked-card conversion is under-specified and ignores pinned partial contracts.** The partial has no `data-label` (`series_table_row_chunk.html:2-70`); the mobile card composition, `th scope`, the exact preserved strings/handlers ("Refresh metadata + Calibre info" `tests/test_series_refresh.py:495`; "Not linked — Match to Calibre series"/`openSeriesCalibreMatch` `tests/test_tracked_series_calibre_link.py:146`; `tag_display`/`safe_url` pins), and the fact that the a11y scan excludes partials (`tests/test_ui_polish.py:174`; row toggle only has `title`, partial `:4`) are not addressed. Fix: add the cell-by-cell contract and extend the a11y/static checks to partials.
5. **B5 — Mobile layers (UX-005/006/007) are not buildable as specified.** Missing `viewport-fit=cover` (`base.html:5`), exact active-tab mapping (including `/downloads/manual-pickup` and More), sheet scroll-lock/focus-trap/focus-return, and an unambiguous z-index/offset ladder ("top-center … above the tasks button" is contradictory); test-segment constraints for `#mobile-menu` (`tests/test_nav_structure.py:265-287`) are not acknowledged. Fix: add the missing mechanics and a layout acceptance test.
6. **B6 — §2 access matrix and non-negotiable #1 overclaim reachability.** "Series sync / match / backfill / link — Series page actions + palette" is false (the palette has no per-series actions), "More sheet search link" does not exist in UX-006, and "every one of the 125 routes … two taps" conflates 10 pages with API routes. Fix: rewrite the matrix and the non-negotiable with the 10-page/two-tap truth and the header command trigger for mobile search.
7. **B7 — §3.1/UX-011 Dashboard contract is counterfactual and test-blind.** 3.1 claims dashboard Download "keeps the existing in-place state update pattern", but it reloads today (`index.html:266-281`); the Quick-actions card repeats the palette action inventory without the feedback matrix, and the in-place change needs an explicit `index.html` test-update entry while keeping pinned queue/tag strings (`tests/test_downloads_page_views.py:164-175`; `tests/test_tag_display_gaps.py:64-68`).
