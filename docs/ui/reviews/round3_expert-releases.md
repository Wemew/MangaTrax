## 3. New blocking issue

**B1 — Tasks widget and the settings save bar can overlap on mobile, violating acceptance #2.**
v0.3 assigns `settings sticky save bar = z 45, bottom (above tab bar on mobile)` and `Tasks = z 55, bottom-right, offset above bottom bar`, and claims Tasks "can never … collide with the settings save bar (45)" (v0.3:89, 95, 101, 336). Numerically 55 > 45, both layers are bottom-right, and no rule hides/offsets one against the other; on `/settings` in the dirty state (360 px) the save bar sits directly above the tab bar while the Tasks button sits 0.75 rem above the bottom bar — the same band. Today's markup confirms the two positions (`settings.html:860` save bar; tasks bottom rule in the spike `base.html:195`), so a computed-CSS review at 360 px would fail the design's own acceptance criterion.

**Concrete amendment (one line + one test):** add to UX-007/UX-030 and UX-013: "While `#settings-save-bar` is visible (add `body.mt-save-open` when it appears), `#global-tasks` is hidden, inert and pointer-events-none (same rule as `body.mt-modal-open`), and restored when the bar hides; alternatively set Tasks z to 44 and give it `bottom = save-bar top + 0.5 rem` while the bar is visible. Correct the sentence 'can never collide with the settings save bar (45)' — with z=55 Tasks is above it; the guarantee comes from mutual exclusion, not z." Add one assertion to the new suite (`body.mt-save-open #global-tasks` hidden/inert) and one line to acceptance #2.

Everything else in the v0.3 delta is accurate. No other blocking issues remain; non-blocking items listed in §2 and the following: (i) Downloads five-builder/table-semantics text is missing despite the brief (§1); (ii) duplicate "5." numbering (v0.3:20/23); (iii) three §7→§4 pointers; (iv) badge-id wording; (v) UX-019 "may add to the same counter" ambiguity; (vi) stale acceptance #5; (vii) M5/M8/M13 residuals; (viii) optional page-matrix table.

## 4. Verdict

v0.3 closes the round-2 gaps that matter for aspect A/C: Tasks is below all backdrops with a correct hidden/inert scope and preserved live regions, the offline-banner layer and failure predicate are specified, the Discovery tab pattern is complete ARIA, the nine partial icon buttons are named, the test matrix now covers the release-state/load-more/post-date/performance/tasks-toast pins, and G-27/G-43 are honest with a verifiable acceptance checklist.
